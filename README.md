# Frezanz — Health & Wellness Writing Portfolio

A single-page portfolio/application site tailored to the Health & Wellness Blog Posts freelance brief.

## Included
- Evidence-led health and wellness positioning for European audiences
- 800–1,000-word sample article
- SEO title, meta description and keyword-rich headings
- Linked WHO, NHS, EFSA and PubMed sources
- Practical, non-promotional editorial approach
- Responsive, CMS-friendly static HTML/CSS

## Run
Open `index.html` directly or serve the directory from any static web server.

## Customize
Replace `hello@example.com` in `index.html` with the preferred contact email before publishing.
