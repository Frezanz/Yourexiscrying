# BTYA — Bijoypur Tinali Youth Association

High-end, mobile-first community hub for the Bijoypur Tinali Youth Association.

## Included
- Identity, purpose and principles
- Searchable member directory UI with role filters
- Proposed leadership / coordination / volunteer structure
- Planning board for initiatives and progress
- Expandable rules & regulations framework
- Community / youth / learning / leadership sections
- Connection / invitation area
- Responsive mobile design
- Interactive Three.js network scene with pointer and scroll movement
- Performance-conscious WebGL settings

## Important
No real member names, contact details, official rules or completed projects are invented. Member cards and rules are a starting structure and should be replaced/approved by BTYA.

The current build is a polished public-facing foundation, not yet an authenticated member app. Real member connection requires a backend such as Supabase/Firebase plus authentication, permissions and a private member area.
